# Page-specific design overrides

Create a route-named Markdown file here only when a page needs a deliberate
exception to the project master. Keep the override narrow and link it back to
[`../MASTER.md`](../MASTER.md).

Active overrides: [`epg.md`](epg.md) (programme timeline),
[`channels.md`](channels.md) (station schedule dialog) and
[`outputs.md`](outputs.md) (feed editor). Other routes (`dashboard`,
`sources`, `programme-detail`) follow the master unchanged. An override never replaces the
master accessibility, responsive, interaction, or security rules unless the
change is explicitly reviewed and the master is updated too.
